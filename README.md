# jjeanjacques.github.io

Blog pessoal de [jjeanjacques10](https://github.com/jjeanjacques10) publicado no GitHub Pages usando Hugo.

## 🚀 Tecnologias

- [Hugo](https://gohugo.io/) - Gerador de sites estáticos
- [hugo-primer-theme](https://github.com/qqpann/hugo-primer) - Tema baseado no Primer CSS do GitHub
- [GitHub Pages](https://pages.github.com/) - Hospedagem

## 📁 Estrutura do Projeto

```
├── .github/
│   └── workflows/
│       └── deploy.yml          # Configuração do GitHub Actions
├── content/
│   └── posts/
│       └── primeiro-post.md    # Post de exemplo
├── themes/
│   └── hugo-primer-theme/      # Tema
└── hugo.toml                   # Configuração do site
```

## ⚙️ Desenvolvimento local

1. Instale o [Hugo](https://gohugo.io/installation/)
2. Clone o repositório
3. Execute `hugo server -D` para iniciar o servidor de desenvolvimento
