# Bem-vindo ao meu blog! 🎉

Este é o meu primeiro post usando **Hugo** publicado no **GitHub Pages**.

## Sobre este blog

Este blog foi criado com [Hugo](https://gohugo.io/), um gerador de sites estáticos rápido e moderno, utilizando o tema [hugo-primer](https://github.com/qqpann/hugo-primer) baseado no design system Primer do GitHub.

## Por que Hugo?

- ⚡ **Rápido**: Hugo é um dos geradores de sites estáticos mais rápidos disponíveis
- 📝 **Simples**: Escreva posts em Markdown
- 🚀 **GitHub Pages**: Deploy automático via GitHub Actions
- 🎨 **Personalizável**: Muitos temas disponíveis
