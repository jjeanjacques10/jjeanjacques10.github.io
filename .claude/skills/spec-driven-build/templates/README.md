Templates e referências úteis para a skill `spec-driven-build`.

Uso rápido:

- Copie `SDD-template.md` para `docs/<feature>/SDD.md` e preencha os campos.
- Copie `TASK-template.md` para `docs/<feature>/tasks/TASK-1-<descricao>.md` e preencha.

Boas práticas:

- Sempre referencie arquivos do repositório com caminho relativo e número de linha quando alterar código.
- Mantenha cada task pequena e com critério de aceite verificável.
